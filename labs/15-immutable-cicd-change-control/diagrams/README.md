# Diagrams — Immutable CI/CD Change Control & Deployment Validation

## `architecture.tldr`

Dark-mode architecture flow for this lab (tldraw JSON).

### Open

1. Go to [https://www.tldraw.com](https://www.tldraw.com)
2. Use **menu → file → open** and select `architecture.tldr`
3. If the canvas theme is light, switch the tldraw UI to **dark** (the diagram shapes already use a dark background panel)

### Edit

Re-run the portfolio generator after changing `labs/catalog.json`:

```bash
node scripts/generate-labs.mjs
```
