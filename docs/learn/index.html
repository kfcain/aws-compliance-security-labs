AWS Compliance & Security Labs

One page to visualize and learn all 17 labs. Filter by framework, walk a guided path, and open each lab's walkthrough, risk, and assessment.

What this portfolio is

Combined monorepo of modular AWS labs for NIST 800-171/800-53, ISO 27001, PCI DSS, and FedRAMP 20x (CR26) KSI automation

Target frameworks: NIST SP 800-171, NIST SP 800-53, ISO 27001, PCI DSS, and FedRAMP 20x / CR26 KSIs. Crosswalks use the Secure Controls Framework static API.

How to use this page

  1. Open Learn path and complete the tracks in order.
  2. Mark a lab complete after you read its walkthrough (or README for labs 16–17).
  3. Use Coverage and Controls when you need the GRC view.
  4. Use Risks when you need likelihood, impact, and ATT&CK technique.

Shared architecture

Data sources → GuardDuty/Config/Inspector → Security Hub → EventBridge → Lambda → Evidence & Alerts
